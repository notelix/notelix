Plain-language privacy

Your data follows

Notelix is open-source, self-hostable software. The operator of the server you select determines that deployment’s policies; the application itself is designed to minimize exposure.

Product privacy overview · Updated August 2026
On this pageWhere data livesBrowser storageEncryptionExternal servicesYour control
01

Where highlight data lives

Highlights, notes, source URLs, and account records are stored by the Notelix server configured in your extension. The public development server is an evaluation environment and may be reset. For durable or sensitive use, deploy your own server and apply your organization’s retention and backup policies.

02

What stays in the browser

The selected server address may sync as a preference. Authentication credentials and client-side encryption material are stored only in the local Chrome profile. Signing out removes those local credentials. Notelix does not add product analytics or advertising trackers.

03

Optional client-side encryption

When enabled during account creation, supported highlight fields are encrypted before transmission. The server cannot recover the plaintext. Your password protects the local encryption key, so a forgotten password cannot be recovered by a server administrator. Search for encrypted accounts requires the local Notelix agent.

04

External services

The product website links to GitHub for source code and release downloads. The extension dashboard does not contact third-party favicon or analytics services. A server operator may place Notelix behind infrastructure of their choice; consult that operator for deployment-specific processing.

05

Your control

You can delete individual highlights from the library, sign out to clear local credentials, switch servers, export or back up the database you operate, and inspect or modify the complete source code. Account-wide deletion is not yet exposed as a self-service UI and should be handled by the server operator.
